# orbit-api — PRs merged 2026-11-16
9 PRs into main. Themes: rate-limiter rollout, quota API cleanup, dependency bumps.

## New functionality
- **Per-tenant rate limits** (#1288, ORB-412): token-bucket limiter with burst and refill from the tenant plan, behind `ratelimit.v2` (`off | shadow | enforce`).
- **Quota usage endpoint** (#1291, ORB-433): `GET /v1/tenants/{id}/quota` returns current usage, limits and the next reset time.

## Bug fixes
- **Quota reset double-count** (#1290, ORB-430): test harness and service now share the injected clock, so resets near a second boundary count once.
- **Pagination cursor** (#1285): cursors survive a sort-key tie instead of skipping rows.

## Things you should know
- `ratelimit.v2` defaults to `shadow`; turning on `enforce` is a config change, no deploy.
- Redis is now required for the limiter. Local dev uses the bundled container; see `docs/dev.md`.
- Bumps: `http-core` 2.14 → 2.15, `redis-client` 5.1 → 5.2.
